Privacy Policy

Last updated: 23 November 2026

This policy describes the information handled by the RG GAMER BOY FF sign-in website as currently implemented. It should be updated if the website begins collecting or processing additional information.

1. Sign-in choices

Google sign-in: Google and Firebase Authentication process sign-in. This website can receive your Firebase user ID, display name, email address and profile photo URL when Google provides them. This website does not receive your Google password.

Guest sign-in: Firebase Authentication creates an anonymous account with a Firebase user ID. A guest account may not have a verified email address and may be difficult to recover if its browser data or session is lost.

Username and password: The separate existing login website is opened at this address. This Firebase sign-in page does not collect the username or password entered on that separate website.

2. Firebase database information

This login page currently uses Firebase Authentication for Google and guest sign-in. It does not write user profile details to the Firebase Realtime Database.

3. Purpose and access

Firebase Authentication is used to establish and maintain the signed-in account. The login page does not display the user’s profile name, email address, or profile photo after sign-in.

4. Browser storage

This website uses browser local storage to remember that the visitor accepted the displayed policy version. Firebase Authentication uses persistent browser session storage so that a returning user can remain signed in, subject to browser settings, sign-out, and Firebase session validity.

5. Third-party services

Google and Firebase provide authentication and database services for the Google and guest options. Their processing is also subject to their own privacy terms and policies.

6. Account information

Google and Firebase process authentication information as part of providing sign-in. This page does not provide an account deletion feature. Users should consult the relevant Google and Firebase account controls for information about those services.

7. Security limitations

Reasonable technical safeguards, including authentication and database access rules, are intended to protect account information. No internet service can guarantee absolute security. Keep your account credentials and devices secure.
